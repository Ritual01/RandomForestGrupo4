# RandomForestGrupo4
Modelo de aprendizaje automático supervisado basado en Random Forest que permita identificar patrones de riesgo de mortalidad por COVID-19 en el Perú utilizando variables demográficas y geográficas provenientes de registros oficiales de defunciones.

## Estructura base del proyecto

```text
.
├── data/
│   ├── raw/
│   └── processed/
├── models/
├── notebooks/
├── src/
│   ├── data/
│   ├── features/
│   ├── models/
│   └── visualization/
└── tests/
```

Esta estructura es intencionalmente vacía para iniciar el desarrollo del pipeline de aprendizaje supervisado con Random Forest.
